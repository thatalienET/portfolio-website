# [AlexSmithDesigns.uk](https://alexsmithdesigns.uk) Portfolio Website

Welcome to the repository for my portfolio website, [alexsmithdesigns.uk](https://alexsmithdesigns.uk). This site is built using a combination of HTML, CSS, and JavaScript, with Nunjucks templating for dynamic content generation. 

## Uses
- [Node.js](https://nodejs.org/en) >= 26 - Required for running scripts
- [nunjucks-to-html](https://github.com/AlexisPuga/nunjucks-to-html) - converts `.njk` templates to complied `.html` files

## To Build
Execute the following commands in your terminal:
```bash
npm install
npm run build
```
